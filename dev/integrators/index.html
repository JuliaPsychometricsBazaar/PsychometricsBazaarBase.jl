PsychometricsBazaarBase.Integrators.LogGridWeights — Type
LogGridWeights(log_values::AbstractVector)

Normalize equal-weight grid log densities without exponentiating their common scale. Stores owned log_values, normalized weights, log_scale (the maximum), and scaled_sum separately to preserve normalization under huge common shifts. Finite real values and -Inf are accepted; empty and zero-mass grids are errors. Floating-point sample types, including BigFloat, are preserved. Treat the stored arrays as read-only; use normalize_grid_weights! to refresh a state.

PsychometricsBazaarBase.Integrators.weighted_grid_moments! — Method
weighted_grid_moments!(
    factors,
    grid,
    weights,
    buffers;
    denominator
)

Return a tuple of (mass, mean, variance) summaries, one per weight buffer:

grid = [-1.0, 0.0, 1.0]
weights = [1.0, 2.0, 1.0]
buffers = (similar(weights), similar(weights))
summaries = weighted_grid_moments!(x -> (1 + x, 1 - x), grid, weights, buffers)
summaries[1] # (mass = 4.0, mean = 0.5, variance = 0.25)

Each buffer stores weights[i] * factors(grid[i])[k] in its element type. factors supplies one factor per buffer, runs once per nonzero base weight, and must not mutate inputs or buffers.

All arrays must have equal, nonempty axes. Supply at least one buffer; buffers must not alias inputs or each other, including across concurrent calls. Factors, base and produced weights must be finite and nonnegative, each channel's mass positive and finite, and coordinates finite wherever produced weights are positive. These per-point numeric requirements are caller obligations. @inbounds also elides shape checks; aliasing, empty-input, mass and denominator checks remain. Buffers may be partially written on failure.

Buffers retain produced weights for centered variance. The optional common denominator follows weighted_grid_moments. Warmed Float32/Float64 calls allocate no heap storage; BigFloat arithmetic may allocate.

PsychometricsBazaarBase.Integrators.weighted_grid_moments — Method
weighted_grid_moments([f,] grid, weights; denominator=nothing)
weighted_grid_moments([f,] grid, state::LogGridWeights; denominator=nothing)

Return (mass, mean, variance) for scalar real samples f(x) (default identity). Inputs are equally indexed vectors. Weights must be finite and nonnegative and have positive finite total mass. Positive-weight samples must be finite; zero weights never evaluate f. Empty/mismatched inputs and invalid values throw.

The first pass fuses mass and an origin-centered first moment, and the second pass sums squared deviations from the mean. No cell width or Bessel correction is applied. The warmed Float32/Float64 path needs no workspace or allocations. BigFloat arithmetic retains input precision but may allocate.

By default both moments divide by the supplied weights' sum. An explicit positive finite denominator replaces that divisor for both moments, including the mean used to center the variance; mass still reports the actual weight sum.

For a log state, moments use normalized weights directly, while mass is a logarithmic number. Additional log_scale and scaled_sum fields preserve the separate normalization metadata. An explicit denominator is in normalized-weight units in this overload. Vector means/covariance and their explicitly sized, caller-owned workspaces are a future extension; this API only accepts scalars.

Log-density grid reductions

LogGridWeights normalizes log-density samples for an equal-weight grid. It is independent of the integration backend and does not add a cell-width factor:

using PsychometricsBazaarBase.Integrators

grid = [-1.0, 0.0, 1.0]
state = LogGridWeights([-1000.0, -1001.0, -1002.0])
mean = weighted_grid_mean(identity, grid, state)
mass = grid_mass(state) # logarithmic number; does not underflow
integral = scale_grid_value(mean, state) # signed logarithmic number

Coefficient functions can return scalars, vectors or matrices. Normalized moments are computed directly from weights; do not recover them by dividing raw integrals or subtracting large logarithms. Points with zero normalized weight skip the coefficient function. For reusable buffers, normalize_grid_weights! returns a new state sharing the supplied log and weight arrays.

Scalar weighted moments

weighted_grid_moments consumes evaluated weights without evaluating a density:

summary = weighted_grid_moments([1e8 - 1, 1e8 + 1], [1.0, 1.0])
# (mass = 2.0, mean = 1e8, variance = 1.0)
summary = weighted_grid_moments(grid, state)
# Moments use state.weights; mass is a logarithmic number.

Mass and an origin-centered first moment share a pass, followed by a pass over squared deviations. This avoids cancellation from subtracting raw second moments. A coefficient overload weighted_grid_moments(f, grid, weights) skips f at zero-weight points. Coefficients must be pure scalar functions, since they are called in both passes. The warmed Float32/Float64 path allocates no scratch; each caller supplies its own input arrays. BigFloat arithmetic may allocate. Vector means and covariance with explicitly sized caller-owned workspaces remain a follow-up.

An explicit denominator divides both moment sums and determines the mean used to center deviations; it does not change the returned actual mass. For log states it is expressed in normalized-weight units. Without an explicit denominator, positive weight rescaling and common log-density shifts leave moments invariant. Log-state results retain log_scale and scaled_sum separately; no tiny absolute density is exponentiated for the normalized moments. All paths retain sum semantics, with no implicit spacing factor or Bessel correction.

Run julia --project=. benchmark/grid_moments.jl for warmed 33-, 65-, and 129-point reductions, reporting setup cost separately from repeated calls.

Moments of transformed weights

grid = [-1.0, 0.0, 1.0]
weights = [1.0, 2.0, 1.0]
buffers = (similar(weights), similar(weights))
summaries = weighted_grid_moments!(x -> (1 + x, 1 - x), grid, weights, buffers)
summaries[1] # (mass = 4.0, mean = 0.5, variance = 0.25)

Each buffer stores weights[i] * factors(grid[i])[k]. The callback runs once per nonzero base weight; centered variance reuses the buffers. The optional denominator works as above.

Use equally indexed, nonempty arrays and nonaliasing buffers. Weights and factors must be finite and nonnegative: these per-point requirements are caller obligations. @inbounds elides shape checks; aliasing and positive finite mass checks remain. See weighted_grid_moments! for the full contract.
