PsychometricsBazaarBase.Optimizers.PreallocatedOptimOptimizer — Type

An Optim.jl based optimizer which reuses its objective between runs.

Construct one with preallocate(optimizer). Within an infinite box the Optim.jl state is reused too, which is why the method and options are fixed when the optimizer is preallocated. Since the objective and state are reused, an instance must not be shared between threads or tasks.

struct PreallocatedOptimOptimizer{InnerT<:PsychometricsBazaarBase.Optimizers.Optimizer, NegatedT<:Union{PsychometricsBazaarBase.Optimizers.NegatedScalarFunction, PsychometricsBazaarBase.Optimizers.NegatedVectorFunction}, ObjectiveT<:NLSolversBase.AbstractObjective, StateT} <: PsychometricsBazaarBase.Optimizers.Optimizer

PsychometricsBazaarBase.Optimizers._optimize_box — Method
_optimize_box(f, lo, hi, initial, optim, opts)

Minimize f within the box [lo, hi] using an Optim.jl method.

The bounds are applied with Optim.Fminbox, apart from methods which handle box constraints themselves. An entirely infinite box means the method runs unconstrained.
